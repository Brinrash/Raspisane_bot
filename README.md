# MAX Schedule Bot

Версия 4.4: распознаются реальные дневные XLSX-замены и файлы «ДОПОЛНИТЕЛЬНО», самостоятельные работы выводятся без пары и времени, добавлена команда сброса сохранённой группы, исправлен импорт сокращённых звонков DOCX/PDF и поддержаны даты диапазоном.

Версия 4.2: подгруппы скрыты в пользовательском выводе; звонки показывают отдельные уроки, пары из двух уроков, перерывы и учебную практику.

Самостоятельный бот расписания **только для MAX**. В проекте нет Telegram-токена, `aiogram` или Telegram-модулей. Бот использует официальный MAX Bot API через HTTPS и собственный небольшой async-клиент на `aiohttp`.

## Возможности

- Выбор курса и группы встроенными кнопками MAX: курс → список групп → нужная группа.
- Автоматическое распределение групп по сотням: `1xx` — 1 курс, `2xx` — 2 курс, `3xx` — 3 курс, `4xx` — 4 курс. Иные номера выводятся в отдельной группе «Другие».
- Кнопки расписания: сегодня, завтра, предыдущая, текущая и следующая недели, а также расписание звонков.
- Расписание занятий выводится отдельными блоками по дням; подгруппы и технические метки «1 п/г» / «2 п/г» пользователям не показываются. В недельном расписании заголовок группы и время последнего обновления показываются один раз.
- Текстовые команды: `/start`, `/help`, `/today`, `/tomorrow`, `/prevweek`, `/week`, `/nextweek`, `/bells`, `/bells 09.11.2026`, `/group`, `/resetgroup`, `/mygroup`, `/myid`, `/chatid`, `/status`.
- Персонально сохранённая группа пользователя MAX в SQLite; у новых пользователей группа не задана по умолчанию. Команда `/resetgroup` сбрасывает только личный выбор текущего пользователя.
- Приём XLSX-файлов от администраторов в личном диалоге и из пересланных публикаций одного разрешённого MAX-канала/чата.
- Импорт изменений расписания звонков из DOCX и текстовых PDF, если дата указана в имени файла или в документе.
- Поддержка пересланных постов: бот проверяет `link.type`, исходный `link.chat_id` и вложения в `link.message.attachments`.
- Поддерживаются отдельные дневные XLSX-замены колледжа с колонками «Пара», «Урок», «Дисциплина», «Ауд.» и блоками «Группа:». Файлы с пометкой «ДОПОЛНИТЕЛЬНО» добавляются к уже загруженной замене, остальные дневные файлы заменяют расписание только для перечисленных групп и указанной даты; остальные дни и группы сохраняются.
- Администраторы получают отчёт об импорте; пользователи затронутых групп — уведомление.
- Самостоятельные работы с пометкой `с/р` отображаются отдельным блоком «САМОСТОЯТЕЛЬНАЯ РАБОТА» без номера пары, времени и кабинета: на них не нужно приходить.
- Звонки выводятся по исходным документам: отдельные номера уроков, завтрак, обед, полдник и две смены учебной практики. Если специальный документ задаёт один общий интервал для нескольких уроков (например, «1,2»), одинаковый интервал показывается одной строкой «1–2-й урок», без дублирования. Для понедельника и вторника–пятницы используются разные штатные распорядки. Специальные изменения на конкретную дату имеют приоритет только в этот день.
- При изменении звонков бот уведомляет всех пользователей, которые выбрали группу.
- Хранение расписания ограничено тремя календарными неделями: предыдущей, текущей и следующей.
- Старые даты и старые записи изменений автоматически удаляются; история импорта ограничена 12 последними событиями.
- Успешно обработанные исходные файлы удаляются из временной папки; неудачные файлы ограничены по сроку и количеству.

Для доступа к платформе может требоваться верифицированный профиль организации, ИП или самозанятого — резидента РФ. Если бот уже создан, используй его отдельный MAX API-токен. ## Установка на Windows 10/11

1. Установи Python 3.11 или новее с https://www.python.org/downloads/ (в установщике включи Add Python to PATH).
2. Распакуй архив в отдельную папку.
3. Запусти `run.bat`. При первом запуске создадутся `.venv` и `.env`.
4. Открой `.env` Блокнотом и заполни `MAX_BOT_TOKEN`.
5. Запусти `run.bat` повторно.
6. Найди своего бота в MAX и нажми Start / отправь `/start`.

Никогда не отправляй токен в переписке и не присылай скриншоты, на которых он виден.

## Сброс сохранённой группы

Выбранная группа хранится индивидуально в SQLite. Если во время тестирования у тебя сохранилась группа 315, это не глобальное значение по умолчанию: отправь `/resetgroup` или нажми «♻️ Сбросить мою группу». Бот удалит только твою запись и предложит выбрать курс/группу заново. У остальных пользователей их выбор останется.

## Администратор MAX

1. Сначала запусти бота и открой личный диалог с ним.
2. Отправь `/myid`. Бот вернёт твой MAX user_id.
3. Останови программу (`Ctrl+C`) и добавь ID в `.env`:

```env
MAX_ADMIN_IDS=123456789
```

Несколько ID перечисляются через запятую. Запусти `run.bat` снова.

Администратор может отправлять новые `.xlsx` в личный диалог с ботом. После импорта бот подтвердит результат.

## Получение файлов из чужого MAX-канала через пересылку

Если исходный канал тебе не принадлежит и ты не можешь добавить туда бота, используй пересылку публикаций в личный диалог с ботом. Добавлять бота администратором в исходный канал **не требуется**.

1. В `.env` укажи ID исходного канала из адреса MAX или из поля `link.chat_id` пересланной публикации:

```env
MAX_SOURCE_CHAT_ID=-69158905315551
```

2. Перезапусти `run.bat`.
3. В MAX открой пост в канале, нажми «Переслать» и выбери личный диалог со своим ботом. Пересылай именно публикацию с прикреплённым XLSX, а не копируй ссылку на файл.
4. Бот проверит `link.type = forward`, сравнит `link.chat_id` с `MAX_SOURCE_CHAT_ID`, затем возьмёт файл из `link.message.attachments` и обработает его.

`MAX_SOURCE_CHAT_ID` здесь работает как allowlist исходного канала, из которого разрешено принимать пересланные файлы. Эта настройка **не предоставляет боту доступ к истории канала** и не позволяет самостоятельно читать новые публикации. Для прямого получения событий из канала бот должен быть добавлен в него с необходимыми правами администратора.

Если ID из адресной строки не совпадает с фактическим `link.chat_id`, бот отклонит пересылку и запишет в консоль строку `origin_chat_id=...`. Используй это значение в `.env` и перезапусти бота. Администратор из `MAX_ADMIN_IDS` по-прежнему может отправлять XLSX непосредственно боту без проверки исходного канала.

Первый запуск Long Polling без сохранённого маркера запрашивает только последнее событие — после старта отправь боту `/start`, а затем перешли тестовый пост с XLSX.

## Режим получения событий и ограничения MAX

Код поддерживает два режима. Если `MAX_WEBHOOK_URL` пустой, запускается Long Polling (удобно локально). Если заданы `MAX_WEBHOOK_URL` и `WEBHOOK_SECRET`, запускается HTTP-сервер и регистрируется MAX Webhook. В логах должно быть явно написано `Режим работы: MAX Webhook`; если видишь `MAX Long Polling`, значит `MAX_WEBHOOK_URL` не задан или пуст.

Webhook требует публичный HTTPS-домен, путь `/webhook` и порт веб-приложения, совпадающий с настройкой Bothost. Long Polling и Webhook одновременно для одного MAX-бота использовать нельзя.

## Как обрабатываются замены

- При получении XLSX парсер извлекает все группы и даты из файла.
- Для каждой пары «группа + дата», которая явно присутствует во входном файле, новая информация заменяет старую.
- Даты и группы, отсутствующие во входном файле, остаются в сохранённом расписании.
- Бот оставляет только даты с понедельника предыдущей недели по воскресенье следующей недели включительно.
- Пример: если сегодня суббота 07.11.2026, окно хранения — 26.10.2026–15.11.2026.
- Новое расписание, опубликованное в пятницу или субботу на следующую неделю, не будет удалено.
- После импорта отправляется отчёт администраторам и уведомления пользователям изменённых групп.

Если ежедневный XLSX содержит только отдельные изменённые пары, а не полный столбец группы на дату, потребуется отдельный парсер под этот формат. Текущий режим замещает данные группы на дату целиком, чтобы не оставить устаревшие пары.

## Расписание звонков

Стандартные времена внесены из двух документов распорядка:
- понедельник: классный час 08:15–09:00, затем уроки 1–8;
- вторник–пятница: десятиминутка 08:00–08:10, затем уроки 1–12.

Время каждого занятия показывается рядом с предметом. Кнопка «⏰ Звонки» и команда `/bells` показывают распорядок на сегодня; если сегодня выходной, бот сразу показывает ближайший учебный день. Команда `/bells 09.11.2026` показывает распорядок на указанную дату.

Для разового изменения пересылай боту DOCX или текстовый PDF с названием, содержащим «звонки», «распорядок» или «время занятий». Дата должна быть указана в названии файла или внутри документа. Если документ задаёт диапазон «с ДД.ММ.ГГГГ по ДД.ММ.ГГГГ», одинаковый распорядок применяется ко всем датам диапазона. DOCX читается напрямую; PDF должен содержать текстовый слой. Для явно сокращённого распорядка список уроков заменяется целиком: обычные поздние уроки и неуказанные перерывы/смены не наследуются. Если PDF — скан, автоматический разбор без OCR не сработает.

## Файлы данных

- `assets/schedule_seed.xlsx` — исходный файл для первого запуска. Если `data/schedule.xlsx` отсутствует, бот скопирует seed-файл в постоянную папку `data`.
- `data/schedule.xlsx` — локальная копия исходного XLSX, используется только при первом создании объединённого JSON.
- `data/schedule.json` — актуальное объединённое расписание.
- `data/max_users.sqlite3` — выбранные группы пользователей MAX.
- `data/max_state.json` — маркер Long Polling и обработанные события.
- `data/bell_schedule.json` — изменения звонков по конкретным датам.
- `data/incoming/` — временные входящие файлы; старые файлы очищаются автоматически.
- `.env` — секретный токен и настройки; не публикуй его.

## Размещение на Bothost

Подробная актуальная инструкция для Git-деплоя, переменных окружения, HTTPS/Webhook и миграции данных находится в `HOSTING_BOTHOST.md`. Для Webhook задайте `MAX_WEBHOOK_URL` и `WEBHOOK_SECRET`; без `MAX_WEBHOOK_URL` локально запускается Long Polling.
